# Coach Badminton V3

Version mobile autonome pour Terminale EPS.

- 6 projets de jeu × 3 niveaux
- consignes précises et zones mesurables
- conseils techniques détaillés
- critères de réussite
- variables simplification / complexification
- diagnostic
- 7e projet « Apprendre un coup technique » avec 6 coups

Ouvrir `index.html` dans un navigateur. Pour un QR code, héberger ce fichier sur un espace web puis créer le QR code vers son adresse.
